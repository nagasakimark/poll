# Classroom Polls

Open `index.html` through any web server (e.g. `python3 -m http.server`) or GitHub Pages.

**Teacher controls**
- Click a picture (or press `1`–`9`, `0`, `-`, `=`) to add a vote; right-click or Shift+click removes one.
- `Z` / Backspace undoes the last vote, `ENTER` finishes and reveals the winner.
- `ESC` back to the poll list, `M` mute, `F` fullscreen.
